# Application notices

The standalone executable embeds the project GPL license, the GPUI input adaptation
license and `THIRD-PARTY-NOTICES.txt`. Open them from Settings > About > Licence, or
run `AtlasManager.exe --licenses` to open a text copy. `AtlasManager.exe --licenses <new-file>`
exports without overwriting an existing file. ISO staging also carries the notices.

Run `../tools/Export-DependencyNotices.ps1` after changing Cargo dependencies.
`-Check` compares the generated text and inventory and rejects unresolved notices;
the production build runs this check before compiling. The generator does not
download license text. Review and check in missing notices with pinned source URLs
and hashes in `supplements.json`. Preserve original author notices, not just SPDX
identifiers or generic license templates. Nested license files are included.

The inventory deliberately includes the full locked Windows resolution, including
build/development packages. `normalWindowsDependency` separates normal edges with
proc macros excluded; this is not a claim about individual linked symbols or code
generated by macros. Over-inclusion avoids treating Cargo edge classification as
proof that attribution is unnecessary. A nonempty notice does not establish license
compatibility or complete compliance: review bundled code, license conditions,
required source provision and changes to the resolution before publication.

Supplemental files normally match `.cargo_vcs_info.json`. Two upstream corrections
add only a missing LICENSE, with no source-code difference from the published crate:
seahash 4.1.0 (`3088c5c912b70b586d27bf553fbe964e025a2c89`) and simd_helpers 0.1.0
(`82040194cd05affb060bf94d6f19f82a771d07fb`). Their exceptions are recorded explicitly
in the supplement inventory. sval_nested ships flattened license symlinks, so its
actual upstream root texts are supplied at the crate's exact VCS commit.

The generated text and source inventory belong in Git and distributions. They do
not contain machine paths. Supplemental hashes cover the downloaded bytes;
Cargo/package-text inventory hashes normalize line endings to LF for portability.
