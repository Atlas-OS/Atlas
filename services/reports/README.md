# Atlas reports

Send an issue or suggestion directly from Atlas Manager or
[the report website](https://reports.atlasos.net). Describe what happened and
include diagnostics if useful. Contact details are optional.

Reports go privately to the Atlas team. Nothing is uploaded automatically:
you choose what to include and confirm before sending. Atlas removes sensitive
identifiers from its diagnostic exports while keeping the technical details
needed to investigate. You're welcome to check the ZIP first. Messages and
contact details are sent as written.

Reports are deleted after 90 days. The team can delete them sooner through the
private dashboard. Access requires an authorized account and two-factor login;
reports and attachments are never publicly listed. Hosting security services may
record connection details, including IP addresses.

You can still export diagnostics and report through Discord if preferred.

This folder contains the public Rust code that validates, stores and manages
reports. See [service details](API.md) for how it works and
[deployment documentation](deploy/README.md) for maintenance.
