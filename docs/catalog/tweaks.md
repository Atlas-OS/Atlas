# Install tweaks

This page lists the tweaks the Atlas install applies, in the order it runs them.
It's for contributors and support, and is generated by `tools/dev/Export-AtlasCatalog.ps1` from `Scripts/Tweaks/tweaks.manifest.psd1`, the definitions it names and the install plan.
Don't edit it by hand: edit the source and regenerate.
The [tweak definition schema](../../playbook/Executables/AtlasModules/Scripts/Tweaks/README.md#tweak-schema) describes every key.

- Categories: 8
- Category tweaks: 173
- Standalone tweaks: 3
- Disabled definitions: 5

## How to read this page

Categories and the tweaks in them follow the manifest order.
Standalone tweaks run at their own positions in [the install plan](../architecture.md#one-plan-and-one-orchestrator), outside the category sequence.

- **Install modes** are the modes in which the install plan runs a category or standalone tweak.
  Fresh is a new install, Upgrade an update to a newer Atlas, Reapply a reinstall of the same version, and Rebase puts Atlas back on a Windows that rebuilt itself during a move to a newer release.
- **Conditions** narrow when a tweak runs within those modes; an empty cell means it runs whenever its category runs.
  "Only with option `x`" needs that choice in Atlas Manager.
  "Fresh installs only" comes from `OnUpgrade = 'Skip'`, and "Fresh and Rebase installs only" adds `OnRebase = 'Run'`.
  "Not on fresh installs" comes from `OnUpgrade = 'Only'`.
  "ARM64 only" and "x64 only" come from `Arch`, and the Windows build conditions from `MinBuild` and `MaxBuild`.
- **Work** lists the keys the definition declares, in the order the install applies them.
  A number counts entries, so `Registry 3` is three registry entries, and `Toggle` names the toggle state the tweak applies and records.
