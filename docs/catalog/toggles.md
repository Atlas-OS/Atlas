# AtlasDesktop toggles

This page lists every toggle: a setting you can change after the install from the AtlasDesktop folder or Atlas Toolbox.
It's for contributors and support, and is generated by `tools/dev/Export-AtlasCatalog.ps1` from the definitions under `playbook/Executables/AtlasModules/Toggles`.
Don't edit it by hand: edit the definition and regenerate.
The [toggle definition schema](../../playbook/Executables/AtlasModules/Toggles/README.md#definition-schema) describes every key.

Toggles: 91.

## How to read this page

Toggles are grouped by their definition folder, `Toggles/<Group>`.

- **Elevation** is the identity the machine work runs as.
  `None` runs in the launcher's own process, `Admin` runs as Administrator after a UAC prompt, and `TrustedInstaller` runs in the silent TrustedInstaller broker.
- **Menu launcher** is the one launcher of a menu toggle, which asks which state to apply.
- **Records no state** marks a one-shot action: Atlas doesn't record it, and updates don't replay it.
- **Value** is the number Atlas records under `HKLM\SOFTWARE\AtlasOS\Services\<Name>` when the state is applied.
- **Restart** is the state's `Reboot` key.
  `Recommend` suggests a restart, `Prompt` says a restart is needed and offers one, `RestartExplorer` restarts File Explorer, and `SignOut` offers to sign out.
- **Work** lists what the state declares.
  A number counts entries, so `Registry 2` is two registry entries.
  `MachineAction` runs with the toggle's elevation, `UserAction` runs as the signed-in user without elevation, and `Action` runs in the launcher's own process.

## Advanced

### MicrosoftStore

Removes Microsoft Store for all users or restores it for your account, downloading its package from Microsoft when needed.

- Elevation: Admin

> [!WARNING]
> Disable removes Microsoft Store for every user on this PC.
> Enable restores it for your account only and may need an internet connection.

| State | Value | Launcher | Restart | Work |
| --- | --- | --- | --- | --- |
| Disable | 0 | `6. Advanced Configuration\Microsoft Store\Disable Microsoft Store.cmd` | None | MachineAction `Remove-AtlasMicrosoftStore` |
| Enable | 1 | `6. Advanced Configuration\Microsoft Store\Enable Microsoft Store (default).cmd` | None | UserAction `Register-AtlasMicrosoftStore` |

### ToggleWindowsUpdates

Turns Windows Update on or off: its services, scheduled tasks, policies and Settings page.

- Elevation: TrustedInstaller
- Menu launcher: `6. Advanced Configuration\Toggle Windows Updates\Toggle Windows Updates.cmd`

> [!WARNING]
> Disabling Windows Update also stops Microsoft Store and the Xbox app installing or updating apps and games.
> Enable usually turns updates back on, but it can fail.
> To stop updates for a while, use Pause Windows Updates in the General Configuration folder instead.

| State | Value | Launcher | Restart | Work |
| --- | --- | --- | --- | --- |
| Disable | 0 | Menu: Disable Windows Updates | Prompt | MachineAction `Disable-AtlasWindowsUpdates` |
| Enable | 1 | Menu: Enable Windows Updates | Prompt | MachineAction `Enable-AtlasWindowsUpdates` |
