Toggle Windows Updates

This launcher turns Windows Update off, or back on.
It's for people who are sure they want no updates at all.
If you only want to stop updates for a while, pausing them is safer; see the last part of this file.

What turning Windows Update off changes

- Windows doesn't download or install updates, including security, driver and feature updates.
- Microsoft Store and the Xbox app can't install or update apps and games, because they download through Windows Update.
- The Windows Update page in Settings is hidden.

Windows asks you to restart after the change.

Turning Windows Update back on

Run Toggle Windows Updates again and choose Enable Windows Updates, then restart when Windows asks.
This usually brings updates back, but it can fail, for example on a PC that other tools have also changed.

Pausing updates instead

Pausing stops updates without turning Windows Update off, and Microsoft Store and the Xbox app keep working.
In the AtlasDesktop folder, open 3. General Configuration, then Pause Updates, and run Pause Windows Updates.
Updates stay paused until you run Unpause Windows Updates in the same folder.
